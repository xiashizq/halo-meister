# Customization image sources

The PNG thumbnails in `Game` were decoded from the cooked
`T_UI_*` customization textures in the user's installed copy of Halo: Campaign
Evolved. They are resized for the picker and allow it to work offline.

The earlier JPEG thumbnails in this directory are official promotional renders
from the Xbox Wire article:

https://news.xbox.com/en-us/2026/06/08/halo-campaign-evolved-prorder-alpha-halo-armory-pack-skins/

The Mark IV preview is an official in-game screenshot from Halo Waypoint:

https://www.halowaypoint.com/news/halo-campaign-evolved-new-missions-reveal-trailer
